# 앵커 사업비 챗봇

한국연구재단 중앙앵커센터의 ‘앵커 사업비 지침 안내 챗봇’입니다.

- 기능설명서: [`docs/앵커 사업비 챗봇 기능설명서.md`](docs/앵커%20사업비%20챗봇%20기능설명서.md)
- 기술 구성·단계별 계획: [`docs/PLAN.md`](docs/PLAN.md)
- 기존 프로토타입(참고용): `docs/reference/smart_anchor_assistant.jsx`

## 현재 진행 상황

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1 | 기반: 로그인·가입 승인·권한, 대화 화면, AI 호출(서버 경유), 1:1 문의함, 대화 열람, 프롬프트 편집 | ✅ 완료 |
| 2 | 지식 적재와 검색: 표준 Q&A 엑셀(버전·되돌리기), 지침·FAQ 원문(조항 분할), 답변 원칙, 답변범위 외 목록, 키워드+의미 혼합 검색, 근거 카드 | ✅ 완료 |
| 3 | 라우팅·안전장치: 답변 유형 4종별 안내 상자, 지역별 연결 연락처, 개인정보 경고·가림, 하루 질문 상한 | ✅ 완료 |
| 4 | 평가 질문집 | 예정 |
| 5 | 운영 루프 | 예정 |
| 6 | 마무리 | 예정 |

> 처음 실행하면 데이터가 없으므로 프로토타입에 들어 있던 지침·FAQ 발췌본이 ‘[임시]’ 문서로 들어갑니다. 실제 지침·FAQ를 올린 뒤 관리 → 지식 데이터 → 지침·FAQ 원문에서 ‘사용 중지’하거나 삭제하세요.

## 처음 실행하기 (내 컴퓨터에서 확인)

필요한 것: [Node.js](https://nodejs.org) 20 이상 (LTS 버전 설치)

```bash
npm install                # 처음 한 번만
cp .env.example .env       # 설정 파일 만들기 (Windows: copy .env.example .env)
npm run dev                # 실행
```

브라우저에서 **http://localhost:5173** 을 엽니다.

- 처음에는 `.env`의 `LLM_PROVIDER=mock`(테스트 모드)라서 AI 비용 없이 화면만 확인할 수 있습니다.
- 실제 AI를 쓰려면 `.env`에서 아래처럼 바꾸고 다시 실행하세요.
  - Gemini: `LLM_PROVIDER=gemini`, `GEMINI_API_KEY=발급받은 키`
  - Claude: `LLM_PROVIDER=claude`, `ANTHROPIC_API_KEY=발급받은 키`
- API 키는 `.env`에만 넣습니다. `.env`는 저장소에 올라가지 않습니다.

## 1단계 확인 순서 (눌러볼 화면)

1. **관리자 첫 로그인**: 아이디 `admin`, 비밀번호는 `.env`의 `ADMIN_INITIAL_PASSWORD`(기본 `change-me-1234`) → 새 비밀번호 설정 화면이 나오는지 확인
2. **가입 신청**: 다른 브라우저(또는 시크릿 창)에서 ‘가입 신청’ → 소속 구분·기관명·지역·사업 유형만 입력하는지 확인
3. **승인**: 관리자 화면 상단 **관리** → ‘가입 승인 대기’에서 승인. 권한(사용자/검수자/관리자) 변경도 해 보기
4. **질문**: 승인된 계정으로 로그인 → 상단 사업 유형 확인 → 질문 입력 → 답변 끝에 면책 문구가 붙는지 확인
5. **대화 목록**: 왼쪽 목록에서 제목 자동 생성, 검색, 삭제 확인
6. **담당자에게 문의**: 답변 아래 ‘담당자에게 문의’ → 문의 등록 → 관리자 **문의 관리**에서 ‘첨부된 대화 보기’로 대화가 함께 왔는지 확인 → 답변 등록 → 사용자 쪽 **1:1 문의**에서 답변 확인
7. **대화 열람**: 관리 → 대화 열람에서 사용자 대화를 읽기 전용으로 보기 (모델·토큰·응답 시간 표시)
8. **프롬프트 수정**: 관리 → 프롬프트·면책 문구에서 수정·저장 → 변경 이력에서 이전 버전으로 되돌리기
9. **잠금**: 일반 계정으로 비밀번호를 10번 틀리면 잠김 → 관리자가 ‘잠금 해제’ / 비밀번호 초기화(임시 비밀번호 발급) 확인
10. **다크모드·모바일**: 상단 달 아이콘, 휴대폰 화면에서도 확인

## 2단계 확인 순서 (지식 데이터)

관리자로 로그인 → 상단 **관리** → **지식 데이터** 탭

1. **표준 Q&A**: [양식 받기]로 형식 확인 → [엑셀 올리기]로 ‘통합질의’ 시트가 있는 엑셀 업로드 → ‘미리보기’ 버전의 건수(확정·미검수·연결형)와 경고(개인정보·빈 칸·중복 번호) 확인 → **[서비스에 적용]**
2. **되돌리기**: 새 엑셀을 또 올려 적용한 뒤, 이전 버전의 [이 버전으로 되돌리기]
3. **지침·FAQ 원문**: 문서 이름·종류(지침/FAQ)를 고르고 PDF 업로드 → [조항 보기]로 ‘제N조’ 단위로 잘 나뉘었는지, 쪽수가 맞는지 확인. 임시 문서는 ‘사용 중지’
4. **답변 원칙**: 엑셀(‘원칙’ 열) 또는 TXT를 [파일에서 불러오기] → 편집기에서 확인 → [저장]
5. **답변범위 외 목록**: 엑셀(대표 질의·안내 문구·담당 부서) 업로드
6. **검색 설정·시험**: 질문을 넣고 [검색] → 어떤 표준답안이 몇 점으로 찾아지는지, ‘근거 있음/없음’ 판정 확인. 필요하면 기준값 조정. 미검수 답안 사용 여부도 여기서 켜고 끔
7. **챗봇에서 질문**: 답변 아래 **참고한 근거** 카드(통합번호·대표 질의, 누르면 답안 전문)가 나오는지, 엉뚱한 질문은 ‘근거 없음’, 범위 외 질문은 ‘답변 범위 아님’으로 AI 호출 없이 처리되는지 확인
8. **대화 열람**: 관리 → 대화 열람에서 답변마다 검색된 통합번호와 토큰 사용량 확인

### 의미 검색 켜기 (선택)

키워드 검색은 바로 동작합니다. 뜻이 비슷한 다른 표현까지 찾는 의미 검색은 모델 파일(약 120MB)이 필요합니다.

```bash
npm run download-model   # 인터넷이 되는 곳에서 한 번 (models/ 폴더에 저장)
```

서버를 다시 시작하면 관리 → 지식 데이터 상단의 검색 방식이 ‘키워드 + 의미’로 바뀝니다. 서버가 인터넷이 안 되면 다른 컴퓨터에서 받은 `models/` 폴더를 서버의 같은 위치에 복사하세요. Docker로 설치하면 이미지를 만들 때 자동으로 받습니다.

## 3단계 확인 순서 (라우팅·안전장치)

1. **연결 연락처**: 관리 → **연결 연락처**에서 17개 지역앵커센터와 e나라도움·교육부·중앙앵커센터의 연락처(대표 번호나 게시판 주소)를 입력하고 저장. 비어 있는 항목은 사용자에게 보이지 않습니다.
2. **질문 상한**: 관리 → 시스템 정보 → ‘질문 상한’에서 1명당·전체 하루 질문 수 설정 (0 = 제한 없음, 한국 시간 0시 초기화)
3. **답변 유형별 화면** (일반 사용자 계정으로 확인)
   - 근거 답변: 초록 표시 + 근거 카드
   - 확인 필요(연결): 근거 답안이 ‘연결형’일 때. 노란 상자에 **내 지역** 앵커센터 연락처 + [담당자에게 문의]
   - 답변 범위 아님 / 근거 없음: AI를 부르지 않고 안내 + [담당자에게 문의]
4. **개인정보**: 질문에 `010-1234-5678` 같은 번호를 넣고 보내기 → 경고 창 → [가리고 보내기]를 누르면 `[전화번호]`로 바뀌어 저장됩니다. (화면 경고를 거치지 않아도 서버가 한 번 더 가립니다)
5. **상한 도달**: 상한을 작게(예: 3) 바꾼 뒤 질문을 계속 보내 안내 문구와 입력창 아래 ‘오늘 질문 n/3’ 표시 확인

## 운영 참고

- **관리자 비밀번호를 잊었거나 관리자 계정이 잠겼을 때**: 서버에서 `npm run reset-admin -- admin` 실행 → 임시 비밀번호 발급
- **데이터 백업**: DB는 `data/chatbot.db` 파일 하나입니다. 서버를 멈춘 뒤 이 파일(그리고 같은 폴더의 `-wal`, `-shm` 파일)을 복사하면 백업됩니다.
- **비밀번호 규칙**: 8자 이상, 영문과 숫자 포함. 서버에는 해시로만 저장됩니다.
- **로그인 유지 시간**: `.env`의 `SESSION_HOURS` (기본 8시간)

## 서버에 설치하기 (Docker)

```bash
docker build -t anchor-chatbot .
docker run -d --name anchor-chatbot -p 3000:3000 --env-file .env -v anchor-data:/app/data anchor-chatbot
```

브라우저에서 `http://서버주소:3000` 으로 접속합니다. HTTPS로 서비스할 때는 `.env`에 `COOKIE_SECURE=true`를 넣으세요.
